# OffensiveX — Phases (SUPERSEDED)

**This document is superseded.** It defined sixteen implementation phases (Foundation → Hardening) for the original fixed-pipeline design, each with detailed tasks/tests/acceptance criteria. See ADR-021 in [Decision.md](Decision.md) for why the project pivoted to an agent-based architecture.

The current build order is [roadmap/roadmap.md](roadmap/roadmap.md) (P0–P19). Kept only as a pointer so old links still resolve.
